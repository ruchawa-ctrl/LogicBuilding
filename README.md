# LogicBuilding

A collection of 188 C and Java programs, organized into 40 assignments, built as part of ongoing logic-building and problem-solving practice. Each assignment tackles a concept incrementally — starting with a foundational problem and building up through related variations.

## 📁 Repository structure

Files are named using an **Assignment number** and, where an assignment has multiple parts, a **Part number**:

Examples:
- `A1.c` — Assignment 1 (single-part)
- `A10_3.c` — Assignment 10, Part 3
- `A17_1.java` — Assignment 17, Part 1

Assignments **1–3** are single-file assignments. Assignments **4–40** each contain **5 parts** (`_1` through `_5`), with each part building on a shared theme — e.g. Assignment 10 moves through circle area, rectangle area, unit conversions, and more.

## 📊 How to navigate this repository

The accompanying `LogicBuilding_Index.xlsx` is the master index for the repository. It maps every file to:

| Column | Description |
|---|---|
| **File Name** | Matches the file in this repository |
| **Assignment No. / Part No.** | Parsed directly from the file name |
| **Language** | C or Java |
| **Problem Statement** | Pulled from the in-code `//QUESTION` comment, where present |
| **Detected Topic** | Auto-inferred from the program's main function name (e.g. `CircleArea`, `MultFact`) — useful as a quick label even where no comment exists |
| **GitHub Link** | Direct link to the file on GitHub |

Open the index, use the filters on each column header to find a topic, language, or assignment, and match the file name to the corresponding program in this repository.

## 🧩 What's inside

The 40 assignments progress from fundamentals to more advanced logic, including:

- **Basics** — arithmetic, division, pattern printing
- **Functions & math** — factorials, multiples, area/unit conversions
- **Conditionals & number theory** — prime checks, digit operations, perfect numbers
- **Loops & pattern logic** — sequences, series, nested loops
- **Strings & characters** — digit/character checks, string manipulation
- **Object-oriented basics (Java)** — Assignments 17–21, covering class/method design in Java before returning to C
- **Data structures** — later assignments (e.g. Assignment 40) implement linked list structures and node-based logic

## 🚀 Usage

1. Open `LogicBuilding_Index.xlsx`.
2. Filter or search by topic, language, or assignment number.
3. Note the **File Name**, then open the matching file in this repository — or click the **GitHub Link** column to jump straight to it.

## 📝 Notes

- Each assignment's parts (`_1` to `_5`) represent related problems building on the same core concept, not repeated attempts at the same problem.
- Some "Problem Statement" entries in the index are blank where the source file doesn't include an explicit `//QUESTION` comment — the "Detected Topic" column offers a best-effort label in those cases, and can be refined manually.
- This repository is intended as a personal reference and revision log — useful before exams, interviews, or as a portfolio of foundational C/Java practice.
